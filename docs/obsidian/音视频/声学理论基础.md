# 声学理论基础

> [【科学基础】声音的物理本质与能量的基本数学表达式 | NewVFX](https://www.newvfx.com/topic/128324)
>
> [声音基础理论详解：波形、频谱、和声与相位原理 | NewVFX](https://www.newvfx.com/topic/50963)

声音是介质中的**机械纵波**: 声源振动 → 邻近粒子被推挤形成疏密 → 能量向外传播, 粒子本身并不随波跑走. 空气里听到的 "声", 就是耳膜感受到的气压起伏.

虚拟歌姬工作可以看成在两条轴上改同一套物理量:

- **调音**: 主要改基频 $F_0(t)$ (音高曲线 / 颤音), 时值, 力度包络, 以及声道共鸣 (元音 / 共振峰)
- **混音**: 主要改频谱能量分布 (EQ), 动态范围 (压缩), 空间 (混响 / 延迟), 并处理掩蔽与相位

进入数字域之后, 这些连续波形被离散成样本, 见 [PCM术语与概念](PCM术语与概念.md).

## 声波的构成参数

一维介质中的简谐波可写成:

$$
s(x, t) = A \sin(kx - \omega t + \phi)
$$

其中 $A$ 是振幅, $k = 2\pi / \lambda$ 是波数, $\omega = 2\pi f$ 是角频率, $\phi$ 是初相位. 传播满足波动方程:

$$
\frac{\partial^2 s}{\partial x^2} = \frac{1}{v^2} \frac{\partial^2 s}{\partial t^2}
$$

空气中声速 $v \approx 343\,\mathrm{m/s}$ (约 $20^\circ\mathrm{C}$), 并有 $v = f\lambda$, 周期 $T = 1/f$.

### 振幅: 能量与响度

振幅是气压偏离平衡位置的最大距离, 决定**能量大小**. 平面波声强:

$$
I = \frac{p_{\mathrm{rms}}^2}{\rho c}
$$

$\rho$ 为介质密度, $c$ 为声速. 振幅越大, 压缩 / 稀疏越剧烈, 单位时间传递的能量越多.

调音里的 Dynamics / Velocity / 响度参数, 混音里的推子, 改的都是这条轴, **不是音高**.

### 频率: 音高

频率 $f$ 是每秒振动次数, 单位 Hz. 人耳大约能听 $20\,\mathrm{Hz}$–$20\,\mathrm{kHz}$, 对 $1$–$4\,\mathrm{kHz}$ 最敏感.

物理上的频率与感知上的**音高**(*Pitch*) 大体对应, 但不等同: 同样 $220\,\mathrm{Hz}$ 的正弦和带气声的人声, 听感音高会受音色与响度牵引. 调音软件画的音高曲线, 本质是在追 **基频** $F_0$.

十二平均律 (A4 = $440\,\mathrm{Hz}$, MIDI 69):

$$
f = 440 \times 2^{(n - 69)/12}
$$

两个频率相差的音分 (*cent*, $100$ cent = 半音):

$$
\mathrm{cents} = 1200 \log_2 \frac{f_2}{f_1}
$$

!!! example "调音时这条公式在干什么"
    把音符量化到音阶, 就是把 $F_0$ 拉到上式给出的目标频率. 颤音 (*Vibrato*) 则是让 $F_0$ 以约 $5$–$7\,\mathrm{Hz}$ 做小幅周期性摆动: 摆得太慢像滑音, 太快像羊叫, 深度过大则音准发虚.

### 波长: 为什么低频难对付

$f$ 越高, $\lambda$ 越短. $100\,\mathrm{Hz}$ 在空气中约 $3.4\,\mathrm{m}$, $1\,\mathrm{kHz}$ 约 $34\,\mathrm{cm}$. 低频绕射强, 指向性差, 在房间和小音箱里更容易堆积; 混音时 "闷 / 轰" 往往先查 $200\,\mathrm{Hz}$ 以下, 物理原因就在这里.

### 相位: 叠加还是抵消

相位描述波形在周期里走到哪一步, 用 $0^\circ$–$360^\circ$. 两列同频波:

- 相位对齐: 振幅相加, 听感更响 / 更实
- 相差 $180^\circ$: 振幅相减, 出现**相位抵消**
- 延迟随频率变化: 梳状滤波 (*comb filter*), 频谱上出现一排缺口

人耳对 "固定相位差" 不敏感, 但对**相位随时间在变**很敏感 — 这就是 chorus / flanger / phaser 能被听到的原因.

!!! note "虚拟歌姬叠加时的相位"
    同一句干声复制一轨再做 $10$–$30\,\mathrm{ms}$ 延迟, 会变宽, 但某些谐波可能被挖空. 和声轨应让 $F_0$ / 音色 / 时机略有差异, 而不是完美克隆. 单声道检查能立刻暴露被相位吃掉的中频.

## 基频, 谐波与音色

纯正弦只有一个频率. 真实人声 (以及几乎所有乐器) 都是**复合波**:

| 名称 | 含义 | 听感 |
| --- | --- | --- |
| 基频 / 第一谐波 $F_0$ | 波形重复的频率 | 音高 |
| 谐波 / 陪音 (*harmonic / overtone*) | $2F_0, 3F_0, \ldots$ | 明亮, "乐音感" |
| 分音 (*partial*) | 不一定是整数倍 | 金属感, 不和谐 |
| 噪声成分 | 无稳定周期 | 气声, 齿音, 摩擦音 |

傅里叶定理: 任何周期波都可看成一组成谐波关系的正弦叠加. $F_0 = 220\,\mathrm{Hz}$ (A3) 时, 二次谐波 $440$, 三次 $660$, 以此类推.

谐波之间的**相对电平及其随时间的变化**, 就是音色. 调音里改 Gender / Tension / Breath, 混音里 EQ, 都是在搬这张 "谐波能量表", 而不是改 $F_0$ 本身.

!!! example "浊音与清音"
    "啊" 是浊音: 声带周期开合 → 有稳定 $F_0$ 和谐波串, 音高曲线画得出来. "丝 / 喝" 接近清音或气声: 频谱更像噪声, 强行修音高往往无效, 应改气声比例, 齿音 EQ 或辅音时机.

## 频谱: 从波形到 EQ

- **波形** (*waveform*): 气压 (或样本值) 随时间变化, 示波器看到的就是它
- **频谱** (*spectrum*): 各频率上的能量, FFT 分析器看到的就是它

EQ 在数学上是线性时不变滤波: 时域卷积 $y(t) = x(t) * h(t)$, 频域就是乘法 $Y(f) = X(f)\, H(f)$. 所以 EQ **不是 "修音准"**, 而是重塑频率轴上的能量分布.

人声混音里几段常用锚点 (是锚点, 不是固定配方):

| 频段 | 常见听感 | 调音 / 混音含义 |
| --- | --- | --- |
| $80$–$200\,\mathrm{Hz}$ | 胸声, 也容易轰 | 低音区能量; 与贝斯抢位置时要让 |
| $200$–$500\,\mathrm{Hz}$ | 厚实或闷 | 鼻音 / 箱音; 多轨人声最易在此堆积 |
| $1$–$4\,\mathrm{kHz}$ | 存在感, 咬字 | 人耳最敏感; 主唱要出来先看这里 |
| $5$–$8\,\mathrm{kHz}$ | 齿音, 空气感 | 去齿音 (*de-esser*) 的主战场 |
| $>10\,\mathrm{kHz}$ | 空气, 也带底噪 | 加得过多会刺, 且传播中衰减更快 |

## 能量与分贝

声压级 (*SPL*):

$$
L_p = 20 \log_{10} \frac{p}{p_0} \quad (p_0 = 20\,\mu\mathrm{Pa})
$$

对数把巨大的气压比压成好算的数. DAW 里常见的是 **dBFS** (满刻度为 $0$), 它量的是数字幅度, **不是**房间里的 SPL; 同一条 $-12\,\mathrm{dBFS}$ 的人声, 用不同监听音量听, SPL 完全不同.

两条容易记混的尺子 (原文有一处把它们写反了):

| 变化 | 声压振幅 | 功率 / 能量 |
| --- | --- | --- |
| $+6\,\mathrm{dB}$ | $\times 2$ | $\times 4$ |
| $+3\,\mathrm{dB}$ | $\times \sqrt{2}$ | $\times 2$ |

自由场中距离加倍, 球面波声强约降 $6\,\mathrm{dB}$. 空气对高频吸收更强, 所以远场先丢掉齿音和空气感, 留下闷闷的中低频 — 这既解释了 "远处听不清词", 也解释了为什么混响尾往往比干声暗.

## 共鸣与共振峰

共鸣 (*resonance*) 是腔体对特定频率的放大: 吉他箱, 房间模态, 以及人的声道.

人声的关键不在声带本身, 而在声道这个滤波器. 声道把谐波串塑成几个凸起, 称为**共振峰** (*formant*):

- $F_1$, $F_2$ 主要决定元音身份 ("啊" / "衣" / "乌" 的差别几乎就是这两峰的位置)
- 更高的共振峰影响个人音色, "像谁"

因此: **同一个 MIDI 音高, 换韵母 = $F_0$ 不变, 共振峰在挪**. 虚拟歌姬里 Gender / Formant Shift 一类参数, 动的是这条共鸣轴; 把它当音高用, 元音会变形, 甚至变成另一个人.

!!! tip "先分清三件事再动手"
    音不准 → 动 $F_0$. 字不正 / 不像这个元音 → 动音素与共振峰. 亮暗不对, 但字是对的 → 动谐波平衡或 EQ. 三者打成一团, 是虚拟歌姬最常见的调坏方式.

## 空间与混响

封闭空间里: 直达声 + 早期反射 + 密密麻麻的后期反射. 后者叠在一起并衰减, 就是混响 (*reverb*).

空间可看成线性系统, 脉冲响应为 $h(t)$, 听到的是卷积:

$$
y(t) = x(t) * h(t)
$$

$h(t)$ 里第一个峰是直达声, 随后几个大峰是早期反射 (房间大小 / 方位), 再往后是指数衰减的混响尾. 衰减 $60\,\mathrm{dB}$ 所需时间称为 **RT60**.

人声上混响给的是 "站在什么空间里唱歌", 不是让字更清楚. 早期反射偏多, 空间感具体; 尾音过长, 辅音被拖脏, 词糊掉. 算法混响用反馈延迟网络近似 $h(t)$, 卷积混响则直接拿真实房间的 $h(t)$ 来乘.

## 心理声学: 耳朵不是传声器

人耳对声音的感知 $\neq$ 物理现实, 混音里真正在对付的往往是下面两条.

**等响曲线** (Fletcher–Munson): 中频 (大约 $1$–$4\,\mathrm{kHz}$) 同样声压听起来更响, 低频和极高频要更大能量才 "够响". 所以:

- 监听开太小声, 会下意识把底鼓 / 贝斯推过头
- "人声被伴奏盖住" 有时不是推子不够, 而是存在感频段被占了

**掩蔽** (*masking*): 强信号会让邻近频率上的弱信号听不见. EQ 的许多 "挖坑", 不是因为那边难听, 而是给主唱腾出没被掩蔽的缝.

音高是感知量, 频率是物理量. 气声变多, 响度骤变, 或共振峰跟着滑, 都会让听感音高偏离 $F_0$ 读数 — 这就是有时 "音高线上已经贴死, 听起来仍飘" 的来源之一.

## 调音与混音对照

| 物理量 | 感知 | 调音里常见操作 | 混音里常见操作 |
| --- | --- | --- | --- |
| 基频 $F_0(t)$ | 音高, 颤音 | 音高曲线, 量化, Vibrato | 一般不动; 自动修音是调音侧的事 |
| 振幅包络 | 力度, 咬字爆发 | Dynamics, 辅音长度 | 推子, 压缩, 自动化 |
| 谐波结构 | 亮 / 暗 / 薄厚 | Tension, Brightness, Harmonics | EQ, 饱和 |
| 共振峰 | 元音, 声线性别感 | 音素, Gender, Formant | 慎用 EQ 去 "改元音" |
| 噪声比 | 气声, 齿音 | Breath, 气声开关 | De-esser, 高频搁架 |
| 相位 / 延迟 | 宽度, 空洞 | 多轨稍错开时机 | 对齐, 合唱, 单声道检查 |
| 空间响应 $h(t)$ | 远近, 房间 | 一般保持干 | 混响, 延迟, 早反射 |

压缩器不改音高, 它只在幅度超过阈值后按比例压低包络, 让强弱差距变小, 人声才能在伴奏里稳住. 过采样等属于插件实现细节, 不是声学本身, 这里不展开.

!!! warning "先听再看分析器"
    频谱仪显示的是物理能量, 不是响度. 一条在 $80\,\mathrm{Hz}$ 很高的人声, 小音量下可能几乎听不见; 一条 $3\,\mathrm{kHz}$ 并不突出的齿音, 却能把整句唱刺穿. 分析器用来定位, 耳朵用来决定动多少.
