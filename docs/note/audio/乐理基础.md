# 乐理基础

> [十二平均律 | 维基百科](https://zh.wikipedia.org/wiki/%E5%8D%81%E4%BA%8C%E5%B9%B3%E5%9D%87%E5%BE%8B)
>
> [音程](https://zh.wikipedia.org/wiki/%E9%9F%B3%E7%A8%8B) / [和弦](https://zh.wikipedia.org/wiki/%E5%92%8C%E5%BC%A6) | 维基百科
>
> [Open Music Theory](https://viva.pressbooks.pub/openmusictheory/)

乐理是一套**约定**: 哪些频率算同一个音, 哪些音算一组, 时间按几拍切.

[调音](调音混音背后的声学理论基础.md)中把基频 $F_0$ 和时值贴到这些格子上; [混音](调音混音背后的声学理论基础.md)处理几个声部怎么叠、别互相[掩蔽](调音混音背后的声学理论基础.md#心理声学). 频率, 音分的物理公式见[频率](调音混音背后的声学理论基础.md#频率), 这里不在赘述.

对照[记谱工具](音频工具概述.md#自动记谱)看伴奏时, 先认调, 和弦, 拍, 再改音高线. 自动记谱是草稿, 乐理才是判断对错的尺子.

| 乐理量 | 调音 | 混音 |
| --- | --- | --- |
| 音高 / 调 | 把 $F_0$ 拉到音阶上的目标音 | 移调, 和声间隔 |
| 音分 | 音准松紧, 颤音深度 | 一般不动音高 |
| 音程 / 和弦 | 旋律是否撞根音, 和声唱几度 | 贝斯占根音, 人声让路 |
| 拍 / 小节 | 音素时值, 气口落点 | 延迟按拍, 自动化对齐小节 |
| 乐句 | 呼吸, 力度弧 | 混响尾巴, 推子起伏 |

## 音高格子

钢琴键相邻两键是**半音** (*semitone*). 十二个半音回到听感上 "同一个音", 只是高或低一倍频率, 叫**八度** (*octave*). 流行, 电子, 歌声合成默认都用[十二平均律](https://zh.wikipedia.org/wiki/%E5%8D%81%E4%BA%8C%E5%B9%B3%E5%9D%87%E5%BE%8B): 每半音频率比是 $2^{1/12}$. 基准通常 A4 = $440\,\mathrm{Hz}$, 对应 MIDI 69.

- **音名** C D E F G A B, 升 (*sharp*, $\sharp$) 高半音, 降 (*flat*, $\flat$) 低半音. C$\sharp$ 与 D$\flat$ 在平均律里是同一个键, 记谱时选哪个看当前调. MIDI 不管这个区别, 所以[自动记谱](音频工具概述.md#自动记谱)导进 MuseScore 后升降号经常要手改.

- **音分** (*cent*): $100$ cent = 1 半音. 调音时:

    - 量化到音阶: 把音高线吸到最近的格子

    - 不要钉死: 真人起音, 滑音, 装饰音会偏十几 cent; 全部集中到 0 cent 会像 MIDI 琴, 听感失真

    - 颤音是格子附近的小摆动, 不是另写一个音

听感音高还受音色, 响度牵引. 音高线上已经贴死, 听起来仍飘, 先查气声和共振峰, 不要继续拧 $F_0$.

## 调与音阶

**调** (*key*) 指定哪组音是 "家里的音". 流行乐里最常见:

- **大调** (*major*): 听感偏明. C 大调的音就是白键 C D E F G A B

- **小调** (*minor*): 听感偏暗. A 小调与 C 大调用同一组音, 互称**关系大小调**

把整首歌整体升高或降低若干半音叫**移调** (*transpose*). 翻唱时伴奏调超出声线舒适音域, 应移调, 而不是把 $F_0$ 硬拉出人声模型的甜区.

!!! tip "先认调再修音"
    伴奏在 G 大调, 旋律里出现的 F 多半是错音 (除非是经过音 / 蓝调音). 没有调, 就无法判断音高线该吸到哪一个格子. 只出和弦进行时, 用 [madmom](音频工具概述.md#自动记谱) 一类工具当草稿, 再用耳朵核对.

一首歌中途换调叫**转调**. 转调处音高线的目标格子会换一套, 不要用前一段的音阶去吸后一段.

## 音程与和弦

**音程** (*interval*) 是两个音之间隔了几个半音. 调音混音里最常用:

| 音程 | 半音数 | 听感 / 用法 |
| --- | --- | --- |
| 同度 / 八度 | 0 / 12 | 加倍厚度; 完美克隆会相位抵消, 和声轨要稍错开时机与音色 |
| 纯五度 | 7 | 稳定, 适合垫底或男声低和声 |
| 大三度 / 小三度 | 4 / 3 | 最常见的人声和声间隔 |
| 大二度 | 2 | 近了就刺, 叠唱时容易打架 |
| 三全音 | 6 | 极不稳, 除非编曲要这个张力 |

**和弦** (*chord*) 是三个及以上音同时响. 最基本的**三和弦** = 根音 + 三音 + 五音. 大三和弦明, 小三和弦暗. 再叠一个七音就是七和弦, 流行乐副歌里很常见.

听伴奏时抓住两件事:

1. **根音**多半在贝斯. 人声旋律长时间钉在根音上会 "黏", 钉在三音上更像唱歌.

2. 和弦一换, 旋律的安全音也换. 前一拍还和谐的音, 下一拍可能变成刺耳的大二度.

!!! note "和声轨"
    主唱唱 C, 和声常见唱 E (大三度) 或 G (纯五度). 不要把同一句干声复制后只做变调插件: 元音和气口会一起变, 听感假. 应在引擎里另写一条旋律, 或至少改时机与音色. 相位问题见声学笔记里的[合唱 / 延迟](调音混音背后的声学理论基础.md#相位).

## 节奏与拍

时间也有格子.

- **BPM** (*beats per minute*): 每分钟多少拍. 伴奏速度的读数.

- **拍号**: 流行默认 $4/4$ (每小节 4 拍, 四分音符为一拍). $3/4$ 是圆舞, $6/8$ 常觉得"两拍里各三小下", 比 $4/4$ 慢.

- **小节** (*bar*): 按拍号捆起来的一组拍. DAW 里的网格, 自动化, 延迟都按它对齐.

音符时值是拍的分数: 全 / 二 / 四 / 八 / 十六. 弱起, 切分是故意不落在强拍上, 这时不要把音素全部吸到网格, 否则沟没了.

调音里音素时长对的是这套格子: 元音可以贴拍, 辅音往往略提前, 咬字才清楚. 混音里延迟按拍来算更稳:

$$
t_{\mathrm{ms}} = \frac{60000}{\mathrm{BPM}} \times \text{(几分音符)}
$$

例如 $120$ BPM 的四分音符延迟是 $500\,\mathrm{ms}$, 八分是 $250\,\mathrm{ms}$. 乱填 $367\,\mathrm{ms}$ 会和鼓点 / 切分对不齐.

## 声部与织体

一首歌同时响的东西可以看成几层:

- **旋律**: 主唱, 调音的主战场

- **和声**: 垫底和弦, 人声和声

- **低音**: 贝斯 / 底鼓, 占根音和 $80$–$200\,\mathrm{Hz}$

- **节奏**: 鼓, 切分, 口齿的辅音

同一音区叠太多, 不是"再推一点人声", 而是[掩蔽](调音混音背后的声学理论基础.md#心理声学): 垫底和弦占了 $1$–$4\,\mathrm{kHz}$, 主唱再响也像糊在墙里. 乐理上的对策是让声部错开音区 (旋律走高, 垫底走中间, 贝斯走根音); 混音上的对策是 EQ 挖坑.

人声音域有限. 选调, 写和声之前先看这句旋律是否挤在声线两端: 过高气声变多音准发虚, 过低则闷, EQ 救不回.

## 乐句

**乐句**是一口气能唱完、听感上有起收的一小段, 常常 2 或 4 小节. 调音的气口, 力度弧, 以及混音的推子 / 混响预延时, 应对齐乐句边界, 不要切在单词中间.

副歌进前的一拍空白, 桥段最后的长音, 都是乐句收束. 这些位置适合做自动化, 不适合塞满延迟反馈.
