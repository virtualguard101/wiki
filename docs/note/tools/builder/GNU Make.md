# GNU Make

一个广泛使用的构建自动化工具，它根据文件依赖关系自动编译和构建计算机程序。make 工具通过读取一个名为 Makefile 的文件来执行构建任务。Makefile 中定义了一系列的规则，用于指示如何从源代码生成可执行文件或其他目标文件。

可有效地管理和自动化 C/C++ 程序的构建过程，提高开发效率。
