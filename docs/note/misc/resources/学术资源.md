# 学术资源与引用

按学科目录整理的教材, 课程, 论文与专题文章, 还有部分通用门户与文献工具. 工程文档, 语言手册, 运维与求职等工程与杂项资料见[工程、求职、杂项资源](工程、求职、杂项资源.md).

在本wiki中引用过的同一本书的各章节链接折叠到书目下; 具体笔记仍保留原文引用.

## 通用门户

- [csdiy: CS自学指南](https://csdiy.wiki/) - 计算机专业课程、自学路径和学习经验的中文资源导航

- [计算机考研杂货铺](https://csgraduates.com/) - 汇总计算机考研院校信息、复习资料和经验的指南

- [Yanyan's Wiki](https://jyywiki.cn/) - 课程讲义、实验和计算机系统学习资料的个人 Wiki

- [小林 x 图解计算机基础](https://www.xiaolincoding.com/) - 以图解方式介绍计算机网络、操作系统和数据库基础

- [Linux C 编程一站式学习](https://akaedu.github.io/book/) - 结合 Linux 环境讲解 C 编程、系统调用和调试实践

## 学术社区与文献工具

### 学术社区

- [CCF 推荐国际学术刊物目录](https://www.ccf.org.cn/Academic_Evaluation/By_category/) - 按计算机学科领域整理的国际学术会议与期刊目录

- [Arxiv](https://arxiv.org/) - 供研究者公开和检索预印本论文的学术平台

- [IEEE Xplore](https://ieeexplore.ieee.org/) - IEEE 出版的期刊、会议论文和技术标准数据库

- [dblp: computer science bibliography](https://dblp.org/) - 计算机科学论文、作者、会议和期刊的书目索引

- [ACM Digital Library](https://dl.acm.org/) - ACM 计算机领域期刊、会议论文及相关出版物数据库

- [MLSys](https://mlsys.org/) / [MLSys Proceedings](https://proceedings.mlsys.org/)

- [USENIX OSDI](https://www.usenix.org/conferences) - USENIX 系统领域会议目录, 包含 OSDI 等会议资料

### 文献查阅

- [Sci-Hub](https://sci-hub.se/) - 学术论文检索与访问站点; 使用前需确认所在地区及机构的访问规则

- [DOI Foundation: 通过 DOI 定位文献](https://www.doi.org/) - DOI 标识符体系的官方网站, 可用 DOI 解析定位数字文献

### 数据库
