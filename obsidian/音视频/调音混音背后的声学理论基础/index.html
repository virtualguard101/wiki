    调音混音背后的声学理论基础¶

    【科学基础】声音的物理本质与能量的基本数学表达式 | NewVFX

    声音基础理论详解：波形、频谱、和声与相位原理 | NewVFX

    声音是介质中的机械纵波: 声源振动 → 邻近粒子被推挤形成疏密 → 能量向外传播, 粒子本身并不随波跑走. 空气里听到的 "声", 就是耳膜感受到的气压起伏.

    在基于歌声合成技术的音频制作(VOCALOID等)中, 两个主要阶段可以看成在两条轴上调整同一套物理量:

    • 调音: 主要改基频 \(F_0(t)\) (音高曲线 / 颤音), 时值, 力度包络, 以及声道共鸣 (元音 / 共振峰)

    • 混音: 主要改频谱能量分布 (EQ), 动态范围 (压缩), 空间 (混响 / 延迟), 并处理掩蔽与相位

    进入数字域之后, 这些连续波形被离散成样本, 使用数字音频处理技术进行存储和处理.

    声波的构成参数¶

    一维介质中的简谐波可写成:

    \[ s(x, t) = A \sin(kx - \omega t + \phi) \]

    其中 \(A\) 是振幅, \(k = 2\pi / \lambda\) 是波数, \(\omega = 2\pi f\) 是角频率, \(\phi\) 是初相位. 传播满足波动方程:

    \[ \frac{\partial^2 s}{\partial x^2} = \frac{1}{v^2} \frac{\partial^2 s}{\partial t^2} \]

    空气中声速 \(v \approx 343\,\mathrm{m/s}\) (约 \(20^\circ\mathrm{C}\)), 并有 \(v = f\lambda\), 周期 \(T = 1/f\).

    振幅¶

    能量与响度

    振幅是气压偏离平衡位置的最大距离, 用于衡量声音的响度与能量大小.

    平面波声强公式:

    \[ I = \frac{p_{\mathrm{rms}}^2}{\rho c} \]

    \(\rho\) 为介质密度, \(c\) 为声速. 振幅越大, 压缩 / 稀疏越剧烈, 单位时间传递的能量越多.

    SV2 的 Loudness, VOCALOID 的 DYN, 以及混音里的推子, 对应的都是这条轴.

    频率¶

    频率 \(f\) 是每秒振动次数, 单位 Hz. 人耳大约能听 \(20\,\mathrm{Hz}\)–\(20\,\mathrm{kHz}\), 对 \(1\)–\(4\,\mathrm{kHz}\) 最敏感.

    物理上的频率与听觉感知上的音高(Pitch)大体对应, 但不等同: 同样 \(220\,\mathrm{Hz}\) 的正弦和带气声的人声, 听感音高会受音色与响度牵引. SV2 的音高曲线 / Pitch Deviation, VOCALOID 的 PIT, 本质都是在基频 \(F_0\)上做文章.

    十二平均律 (A4 = \(440\,\mathrm{Hz}\), MIDI 69):

    \[ f = 440 \times 2^{(n - 69)/12} \]

    两个频率相差的音分 (cent, \(100\) cent = 半音):

    \[ \mathrm{cents} = 1200 \log_2 \frac{f_2}{f_1} \]

    调音的量化

    • 把音符量化到音阶, 就是把 \(F_0\) 拉到上式给出的目标频率.

    • 颤音 (Vibrato) 则是让 \(F_0\) 以约 \(5\)–\(7\,\mathrm{Hz}\) 做小幅周期性摆动: 摆得太慢像滑音, 太快像羊叫, 深度过大则音准发虚.

    波长¶

    \(f\) 越高, \(\lambda\) 越短.

    \(100\,\mathrm{Hz}\) 在空气中约 \(3.4\,\mathrm{m}\), \(1\,\mathrm{kHz}\) 约 \(34\,\mathrm{cm}\). 低频绕射强, 指向性差, 在房间和小音箱里更容易堆积; 混音时感到"闷 / 轰", 往往先留意 \(200\,\mathrm{Hz}\) 以下的频段, 物理原因就在这里.

    相位¶

    相位描述波形在周期里走到哪一步, 用 \(0^\circ\)–\(360^\circ\).

    相位在音频中的应用主要体现在叠加与抵消.

    假设有两列同频波:

    • 相位对齐: 振幅相加, 听感更响 / 更实

    • 相差 \(180^\circ\): 振幅相减, 出现相位抵消

    • 延迟随频率变化: 梳状滤波 (comb filter), 频谱上出现一排缺口

    人耳对"固定相位差"不敏感, 但对相位随时间的变化很敏感. 混音里三类常见的调制效果都靠这件事:

    • Chorus (合唱): 复制信号, 延迟约 \(15\)–\(35\,\mathrm{ms}\), 再用低频振荡器轻微调制延迟 / 音高后与干声混合, 听感像多人同唱

    • Flanger (镶边): 结构类似 chorus, 但延迟更短 (约 \(1\)–\(5\,\mathrm{ms}\)) 且常加反馈, 梳状缺口被扫过频谱

    • Phaser (相位器): 不用延迟线, 用全通滤波器做随频率变化的相移, 再与干声混合产生缺口; 缺口间距不像 flanger 那样按谐波整齐排列, 扫起来更柔

    Tip

    同一句干声复制一轨再做 \(10\)–\(30\,\mathrm{ms}\) 延迟, 会变宽, 但某些谐波可能被挖空. 和声轨应让 \(F_0\) / 音色 / 时机略有差异, 而不是完美克隆. 单声道检查能立刻暴露被相位吃掉的中频.

    傅里叶声学¶

    纯正弦只有一个频率. 真实人声 (以及几乎所有乐器) 都是复合波, 由基频和一系列谐波组成:

    名称 含义 听感
    基频 / 第一谐波 \(F_0\) 波形重复的频率 音高
    谐波 / 陪音 (harmonic / overtone) \(2F_0, 3F_0, \ldots\) 明亮, "乐音感"
    分音 (partial) 不一定是整数倍 金属感, 不和谐
    噪声成分 无稳定周期 气声, 齿音, 摩擦音

    这里的数学原理基于傅里叶定理: 任何周期波都可看成一组成谐波关系的正弦叠加. \(F_0 = 220\,\mathrm{Hz}\) (A3) 时, 二次谐波 \(440\), 三次 \(660\), 以此类推.

    谐波之间的相对电平及其随时间的变化, 就是音色. SV2 与 VOCALOID 里下面几条参数, 以及混音里的 EQ, 动的都是频谱形态:

    物理量 SV2 VOCALOID 听感
    共振峰整体平移 Gender GEN (V1–V4) / Character (V5+) 偏男厚或偏女薄 / 幼, 音高不变. 物理性质见共鸣与共振峰
    谐波亮暗 / 用力感 Tension 无同名; 近 BRI / CLE 升高更亮更锐 (像用力唱), 降低则松 / 暗, 甚至发闷
    气声 Breathiness BRE / Breathiness, 另有 Air 噪声相对谐波的比例升高, 更气、更私语; 过高则字糊、齿音炸
    渲染后的频段增益 (DAW 负责) (DAW 负责) 参考EQ(均衡器)

    Note

    • VOCALOID5 起 Character 升高偏女, 与旧版 GEN 相反.

    • SV2 的 Gender 是共振峰平移, 具体方向以当前版本听感为准.

    • VOCALOID 没有 Tension, 不要把 BRI 当成张力的一一对应.

    浊音与清音

    • "啊" 是浊音: 声带周期开合 → 有稳定 \(F_0\) 和谐波串, 音高曲线画得出来.

    • "丝 / 喝" 接近清音或气声: 频谱更像噪声, 强行修音高往往无效, 应改气声比例, 齿音 EQ 或辅音时机.

    频谱与波形¶

    同一段音频的数据在傅里叶声学的视角下可以被分解为波形和频谱两种形式, 它们是同一信号的两种写法.

    波形¶

    波形(waveform)的横轴是时间, 纵轴是气压(数字音频领域里就是样本值). DAW中那条上下抖动的线, 示波器看到的就是它.

    以 A3 (\(F_0 = 220\,\mathrm{Hz}\)) 的浊音 "啊" 为例: 波形大约每秒重复 220 次. 你能读出音头有多猛, 气声有没有把周期打乱, 但很难一眼看出音感"闷"是因为 300 Hz 太多, 还是 3 kHz 太少.

    频谱¶

    频谱(spectrum) 的横轴是频率(Hz), 纵轴是该频率上的能量(或幅度). DAW 的Spectrum/Analyzer看到的就是它.

    还是那句"啊", 频谱上会在 \(220, 440, 660, \ldots\,\mathrm{Hz}\) 冒出一串峰, 这就是上一节提到的基频与谐波. 峰有多高, 决定亮暗; 峰之间若再叠一团噪声, 就是气声. "闷 / 亮 / 齿音" 这类听感, 大多是在频谱上定位的.

    可以把它想成奶昔和配料表, 波形是搅在一起的液体, 频谱是糖 / 奶 / 冰块各放了多少. 味道来自配料比例, 不是来自搅拌缸的外形.

    两张图怎么互相翻译¶

    傅里叶定理提到: 一段够稳的周期波, 可以拆成许多不同频率的正弦再加回去. 分析器做的就是这件事的离散快算, 叫做FFT (Fast Fourier Transform, 快速傅里叶变换).

    真实听感与分析的差异

    FFT 看的是一小段时间窗口, 不是整首歌的永恒指纹. 窗口太短, 频率刻度会糊; 窗口太长, 音头变化会来不及跟上. 所以频谱仪用来定位问题频段, 听感仍以耳朵为准.

    时域(波形)和频域(频谱)是同一信号的两种写法. 调音软件里的音高线跟踪的是 \(F_0\); 混音里的 EQ 跟踪的是整张频谱.

    EQ的作用¶

    EQ(均衡器)按频段推高或挖低能量, 相当于改配料表, 不改这首歌唱的是哪个音. MIDI 还是 A3, 3 kHz 抬一点, 只是咬字更靠前; \(F_0\) 该飘还是飘. 所以 EQ 不是修音准.

    直观操作:

    • 提升 (boost): 某频段乘上大于 1 的增益, 那一带更响

    • 削减 (cut): 乘上小于 1, 那一带更弱

    • 滤波器类型 只是增益曲线的形状不同: 低切丢掉轰的低频, 钟形 (bell) 对准一小段, 搁架 (shelf) 从某频率起整体抬高或压低

    SV2 / VOCALOID 里的 Gender, Tension, Breathiness 是在合成模型内部改频谱; 渲染进 DAW 之后再挂 EQ, 动的是已经冻住的波形. 前者还能改元音身份, 后者一般只能让已有谐波变响或变暗. 发音咬字的问题, 应回引擎改音素 / Gender, 你不能指望 EQ 把 "衣" 修回 "啊".

    数学原理¶

    把 EQ 看成一个线性非时变系统(输入加倍则输出加倍, 昨天和今天用同一套曲线), 它对频谱做的就是逐频率相乘:

    \[ Y(f) = X(f)\, H(f) \]

    \(X(f)\) 是人声原来的频谱, \(H(f)\) 是你画的那条 EQ 曲线 (在 3 kHz 等于 2, 就是把 3 kHz 加倍), \(Y(f)\) 是处理后的频谱. 没有能量的地方, 乘再大也变不出新的音高, EQ 造不出不存在的谐波.

    同一件事写在时间轴上, 变成卷积:

    \[ y(t) = x(t) * h(t) \]

    \(h(t)\) 是 EQ 的脉冲响应: 给它一个极短的 "咔" (脉冲), 它吐出来的尾巴.

    卷积在这里的含义是: 人声的每一个瞬间都按这根尾巴抹开, 再全部叠回去. 所以 EQ 不只改响度, 极窄的提升也会让波形稍微"拖" 一下, 在听感上有时会像多了一点共振.

    人声混音的常用锚点¶

    频段 常见听感 调音 / 混音含义
    \(80\)–\(200\,\mathrm{Hz}\) 胸声, 也容易轰 低音区能量; 与贝斯抢位置时要让
    \(200\)–\(500\,\mathrm{Hz}\) 厚实或闷 鼻音 / 箱音; 多轨人声最易在此堆积
    \(1\)–\(4\,\mathrm{kHz}\) 存在感, 咬字 人耳最敏感; 主唱要出来先看这里
    \(5\)–\(8\,\mathrm{kHz}\) 齿音, 空气感 去齿音 (de-esser) 的主战场
    \(>10\,\mathrm{kHz}\) 空气, 也带底噪 加得过多会刺, 且传播中衰减更快

    能量与分贝¶

    声压级 (SPL):

    \[ L_p = 20 \log_{10} \frac{p}{p_0} \quad (p_0 = 20\,\mu\mathrm{Pa}) \]

    对数把巨大的气压比压成好算的数. DAW 里常见的是dBFS(满刻度为 \(0\)), 它量的是数字幅度, 不是房间里的 SPL; 同一条 \(-12\,\mathrm{dBFS}\) 的人声, 用不同监听音量听, SPL 完全不同.

    变化 声压振幅 功率 / 能量
    \(+6\,\mathrm{dB}\) \(\times 2\) \(\times 4\)
    \(+3\,\mathrm{dB}\) \(\times \sqrt{2}\) \(\times 2\)

    自由场中距离加倍, 球面波声强约降 \(6\,\mathrm{dB}\).

    空气对高频吸收更强, 所以远场先丢掉齿音和空气感, 留下闷闷的中低频. 这既解释了"远处听不清词", 也解释了为什么混响尾往往比干声暗.

    共鸣与共振峰¶

    共鸣(resonance)是腔体对特定频率的放大, 典型例子有吉他箱, 房间模态, 以及人的声道.

    人声的关键不在声带本身, 而在声道这个滤波器. 声道把谐波串塑成几个凸起, 称为共振峰(formant):

    • \(F_1\), \(F_2\) 主要决定元音身份 ("啊" / "衣" / "乌" 的差别几乎就是这两峰的位置)

    • 更高的共振峰影响个人音色

    同一个 MIDI 音高, 换韵母 = \(F_0\) 不变, 共振峰在挪.

    SV2 的 Gender, VOCALOID 的 GEN / Character, 动的都是这条共鸣轴; 把它当音高用, 元音会变形, 甚至变成另一个人. SV2 的 Mouth Opening 与 VOCALOID 的 OPE / Mouth 更接近开口度, 也会拖动共振峰, 但不是整体平移.

    三大常见问题对应的参数

    • 音不准 → 留意 \(F_0\).

    • 字不正 / 不像这个元音 → 留意音素与共振峰.

    • 亮暗不对, 但字是对的 → 留意谐波平衡或 EQ.

    这三者混为一谈, 是 SV2 / VOCALOID 最常见的调坏方式, 需要先分清三件事再动手.

    空间与混响¶

    封闭空间里, 直达声 + 早期反射 + 密密麻麻的后期反射, 后者叠在一起并衰减, 就是混响(reverb).

    空间可看成线性系统, 脉冲响应为 \(h(t)\), 听到的是卷积:

    \[ y(t) = x(t) * h(t) \]

    \(h(t)\) 里第一个峰是直达声, 随后几个大峰是早期反射(房间大小 / 方位), 再往后是指数衰减的混响尾.

    衰减 \(60\,\mathrm{dB}\) 所需时间称为RT60 (Reverberation Time, 混响时间).

    人声上混响考虑的是"站在什么空间里唱歌", 不是让字更清楚. 早期反射偏多, 空间感具体; 尾音过长, 辅音被拖脏, 词糊掉. 算法混响用反馈延迟网络近似 \(h(t)\), 卷积混响则直接拿真实房间的 \(h(t)\) 来乘.

    心理声学¶

    人耳对声音的感知(心理学) \(\neq\) 物理现实(声学), 混音里真正在对付的往往是下面两条.

    等响曲线(Fletcher–Munson): 中频(大约 \(1\)–\(4\,\mathrm{kHz}\))同样声压听起来更响, 低频和极高频要更大能量才"够响". 所以:

    • 监听开太小声, 会下意识把底鼓 / 贝斯推过头

    • "人声被伴奏盖住" 有时不是推子不够, 而是存在感频段被占了

    掩蔽(masking): 强信号会让邻近频率上的弱信号听不见. EQ 的许多"挖坑", 不是因为那边难听, 而是给主唱腾出没被掩蔽的缝隙.

    音高是感知量, 频率是物理量. 气声变多, 响度骤变, 或共振峰跟着滑, 都会让听感音高偏离 \(F_0\) 读数, 这就是有时"音高线上已经贴死, 听起来仍飘"的原因之一.

    调音混音参数与听感的对应关系¶

    物理量 感知 SV2 VOCALOID 混音
    基频 \(F_0(t)\) 音高, 颤音 Pitch Deviation, Vibrato PIT, 滑音 / 颤音 一般不动
    振幅包络 力度, 咬字爆发 Loudness, 音素时长 DYN, 音素时长 推子, 压缩, 自动化
    谐波结构 亮 / 暗 / 薄厚 Tension, Tone Shift, Vocal Mode BRI, CLE EQ, 饱和
    共振峰 元音, 声线性别感 Gender, Mouth Opening, 音素 GEN / Character, OPE / Mouth, 音素 慎用 EQ 去 "改元音"
    噪声比 气声, 齿音 Breathiness, Voicing BRE / Breathiness, Air De-esser, 高频搁架
    相位 / 延迟 宽度, 空洞 多轨稍错开时机 多轨稍错开时机 对齐, 合唱, 单声道检查

    压缩器不改音高, 它只在幅度超过阈值后按比例压低包络, 让强弱差距变小, 人声才能在伴奏里稳住. 过采样等属于插件实现细节, 不是声学本身, 这里不展开.

    先听再看分析器

    频谱仪显示的是物理能量, 不是响度. 一条在 \(80\,\mathrm{Hz}\) 很高的人声, 小音量下可能几乎听不见; 一条 \(3\,\mathrm{kHz}\) 并不突出的齿音, 却能把整句唱刺穿. 分析器用来定位, 耳朵用来决定动多少.
